# AI Engineering Masterclass

Course aligned to Andrew Ng’s AI Engineering Skills Map. Stack matches sellhausen.com: Next.js 15, Tailwind v4, DM Sans / Instrument Serif / Geist Mono.

**Agents: read `AGENTS.md`.** Curriculum: `SPINE.md`.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

Canonical chapter text lives in `constants.ts`. Edit `chapters/*.md` first, then copy in (escape backticks). Pedagogical order is `lib/courseOrder.ts`.
